# Screenshots

**These are design mockups, not simulator captures.**

The container this project is developed in has no macOS, no Xcode and no iOS simulator (see
`docs/ARCHITECTURE.md` §14), so nobody has yet run ParkLife on a device. Rather than skip the
visual side entirely or draw something made up, these images are generated by
`Tools/mockup/` and are driven by the project's real data:

| What is real | Source |
|---|---|
| Terrain — hills, the lake, forest patches, the entrance apron | A JavaScript port of `MapGenerator` using the same SplitMix64 generator and the same `generationSeed` from `maps.json`, so it is the terrain the game generates |
| Park layout | The same coordinates and door-anchored placement rules as `GameSetup.makeDemoPark` |
| Buildings, prices, footprints, capacities, tiers | `Sources/ParkLifeCore/Resources/Catalog/*.json`, the same files the game loads |
| Projection, tile metrics, draw order, placeholder colours | The same constants as `IsometricProjection` and `PlaceholderArt` |
| UI layout, wording, overlays | The SwiftUI views in `App/ParkLife/UI/` and `Localizable.strings` |

| What is illustrative | Why |
|---|---|
| Guest and staff positions | Only a running simulation produces those, and that needs a Swift toolchain |
| HUD figures, bookings, reviews, chart values | Plausible values chosen to show the layout; the real ones come from a run |

Regenerate with:

```sh
python3 Tools/mockup/build.py          # inlines the catalog into a single HTML file
cd Tools/mockup && npm install playwright && node shoot.mjs
```

| File | Device | Shows |
|---|---|---|
| `01-ipad-park-and-bookings.png` | iPad landscape | Park view, HUD, building inspector, bookings panel beside the park |
| `02-ipad-overlay-and-objectives.png` | iPad landscape | Crowding overlay with legend, park ratings and scenario objectives |
| `03-iphone-build-mode.png` | iPhone | Build mode with a green placement preview, build bar and navigation |
| `04-iphone-finances.png` | iPhone | Finances as a contextual sheet, with the profit trend and pricing controls |
| `05-iphone-guest-inspector.png` | iPhone | Scenery overlay and a selected guest with needs and their latest thought |

Once the project is built on a Mac these should be replaced with real simulator captures.
